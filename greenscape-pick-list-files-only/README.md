# Greenscape Warehouse Pick List Generator

Turns an EasyPV design and a customer quote into a warehouse pick list and a
Wasp import file. Drag the two PDFs in, check what it read, generate.

**Internal Greenscape tool. Not for distribution outside the company** — it has
our full Wasp item catalogue, stock figures and picking logic built into it.

---

## Using it

**From this repo:** open `index.html` above and click **Download raw file**.

> **Before switching on GitHub Pages, read this.** A Pages site published from a
> private repo is still reachable by anyone on the internet who has the URL —
> restricting it to repo members needs GitHub Enterprise Cloud. Because this file
> carries our item catalogue and stock figures, a Pages link would put all of it
> in public view. For an internal always-current link, put the file on SharePoint
> or Teams instead, where Microsoft 365 sign-in protects it.

**Offline copy:** open `index.html` above, click **Download raw file**, and save
it anywhere. It is a single self-contained file — no install, no internet needed,
and it can be emailed. Rename it to something recognisable if you like; the name
does not matter.

Everything runs in your own browser. No quote, design or customer detail is
uploaded anywhere.

## What you do

1. **Drop in the two PDFs** — the EasyPV design and the customer quote. It reads
   the customer name, panel count and model, string count, roof layouts, inverter
   and battery from them.
2. **Check what it read.** Every field is editable. It is a reader, not an oracle
   — if a quote is worded unusually it can miss something.
3. **Fill in what the PDFs do not say** — roof hook counts, tile type, whether
   the fuseboard goes indoors or outdoors, EV chargers, Tigo optimisers.
4. **Generate.** You get the pick list on screen, plus two downloads: the pick
   list as a spreadsheet, and the Wasp import file.

## Read the flags

Any line the tool is not certain about is marked. Two kinds:

- **CHECK** on a pick line — a substituted or assumed part. The reason is on the row.
- **NEEDS MANUAL CHECK** — a list at the bottom of things it could not work out,
  usually because an input was blank or a quote said something unexpected.

Neither stops you generating. Both mean look before you pick.

It will never invent a Wasp item number. If it cannot find a code for something
it lists the item by description and flags it, rather than guessing.

## How the logic works

`Greenscape_Pick_List_Logic.xlsx` in this repo is the full picking logic written
out in plain English — every inverter kit, battery band, roof type, fuseboard
ladder and quantity rule, with a Correct? column. Fourteen sheets:

| Sheet | What it holds |
|---|---|
| Read me | How to review the workbook |
| Rules | The 33 rules the tool follows |
| Check these | 12 judgement calls that still need a decision |
| Quantity rules | All 46 "how many" rules and how they resolve |
| Inverters / Batteries / Roof types | The kit for every model |
| Fuseboards | Way counting and the board ladders |
| Car chargers / Tigo / Additional items | The optional sections |
| Warnings | Every warning it can raise |
| Applied | The 21 changes from Dan's review |

If something picks wrong, that workbook is where to find out why. Mark the row
and send it back.

## Known open items

Twelve things in the **Check these** sheet still need a decision, including:

- **1840 (8 way busbar)** on the IntelliHome 5–8 battery band — the review
  contradicted itself on this part. Kept and flagged pending a decision.
- **The Tesla Wall Connector rule cannot fire** — 1898 is not in the charger list.
- **2237** (the RCBO picked with every charger) shows no stock; 2600 and 2397 are
  the alternatives that do.
- **The Wasp import has not been tested end to end.** Everything checkable from
  here is right, but no one has uploaded a generated file to Wasp yet. Worth
  doing on a job already picked by hand before trusting it.

## Rebuilding it

The `index.html` here is a **built artefact**, not source. It is generated by a
Python pipeline from the Wasp picking spreadsheet and the item master. Editing
the 2.4MB HTML by hand is a bad idea and will be overwritten by the next build.

The pipeline (`build.py`, the HTML template, the source spreadsheet, 21 browser
tests) is **not in this repo**. Ask Dan for it before attempting any change to
the logic.

## Data in here

Item codes, descriptions and stock figures for 1,850 Wasp items, and the picking
recipe for every inverter and battery we fit. Keep the repo private.
